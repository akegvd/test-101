# บทที่ 1: Unit Test แรกด้วย pytest

## Unit test คืออะไร

Unit test คือโค้ดที่ทดสอบ "หน่วยเล็กที่สุด" ของโปรแกรม เช่นฟังก์ชันเดียว
โดยส่งข้อมูลเข้าไปแล้วตรวจว่าผลลัพธ์ตรงกับที่คาดไว้หรือไม่
ถ้าวันหนึ่งเราแก้โค้ดแล้วทำให้พฤติกรรมเปลี่ยนโดยไม่ตั้งใจ เทสต์จะฟ้องทันที

## ไฟล์ในบทนี้

| ไฟล์ | หน้าที่ |
| --- | --- |
| `discount.py` | ฟังก์ชัน `calculate_discount(price, percent)` คืนราคาหลังหักส่วนลด |
| `test_discount.py` | เทสต์ของฟังก์ชันข้างบน เขียนแบบ Arrange / Act / Assert |

## รูปแบบ Arrange / Act / Assert (AAA)

ทุกเทสต์แบ่งเป็น 3 ขั้น ให้อ่านง่ายและรู้ว่ากำลังทดสอบอะไร

1. **Arrange** เตรียมข้อมูลนำเข้า
2. **Act** เรียกฟังก์ชันที่ต้องการทดสอบ (ควรมีแค่บรรทัดเดียว)
3. **Assert** ตรวจผลลัพธ์

```python
def test_applies_ten_percent_discount():
    # Arrange
    price = 200
    percent = 10

    # Act
    result = calculate_discount(price, percent)

    # Assert
    assert result == 180
```

## ควรทดสอบอะไรบ้าง

เทสต์ในบทนี้แบ่งเป็น 3 กลุ่ม ซึ่งใช้ได้กับเกือบทุกฟังก์ชัน

- **กรณีปกติ** เช่น ลด 10% จาก 200 ได้ 180
- **กรณีขอบ** เช่น ลด 0%, ลด 100%, ทศนิยมที่ต้องปัดเศษ
- **กรณีข้อมูลผิด** เช่น ราคาติดลบ หรือเปอร์เซ็นต์เกิน 100 ต้องเกิด `ValueError`
  (ตรวจด้วย `pytest.raises`)

นอกจากนี้ยังมีตัวอย่าง `@pytest.mark.parametrize` ที่รันเทสต์เดียวกันกับข้อมูลหลายชุด

## วิธีรันเทสต์

ต้องมี Python 3.9 ขึ้นไป

```bash
# 1. สร้างและเปิดใช้ virtual environment (ทำครั้งเดียว)
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 2. ติดตั้ง pytest (รันจากโฟลเดอร์หลักของ repo)
pip install -r requirements.txt

# 3. เข้าโฟลเดอร์บทเรียนแล้วรันเทสต์
cd lesson-01-unit-tests
pytest -v
```

ถ้าทุกอย่างถูกต้องจะเห็นประมาณนี้

```
test_discount.py::test_applies_ten_percent_discount PASSED
...
============================== 7 passed in 0.02s ==============================
```

## แบบฝึกหัด

1. **ทำให้เทสต์พัง** ลองแก้ `discount.py` ให้คำนวณผิด เช่นเปลี่ยน `100 - percent`
   เป็น `100 + percent` แล้วรัน `pytest` ดูว่าข้อความ error บอกอะไรเรา จากนั้นแก้กลับ
2. **เพิ่มเทสต์เอง** เขียนเทสต์ว่า ลด 25% จาก 80 ต้องได้ 60
3. **เพิ่มความสามารถ** เพิ่มพารามิเตอร์ `max_discount` เพื่อจำกัดส่วนลดไม่ให้เกินกี่บาท
   (เช่น ลด 50% จาก 1000 แต่ไม่เกิน 300 ต้องได้ 700) เขียนเทสต์ก่อน แล้วค่อยแก้โค้ดให้ผ่าน
